## 🐛 Quick Troubleshooting

| Issue | Solution |
|-------|----------|
| Login fails | Clear browser cache (Ctrl+Shift+Del) and try again |
| Dashboard empty | Refresh page (F5) or logout/login |
| Charts don't show | Open browser DevTools (F12) → Console, check for errors |
| Slow loading | Server is dev mode - normal, will improve with production DB |
| Can't find credential | All 22 accounts listed above - check spelling |

1. **Open in Incognito Window**: Logout faster between tests

3. **Test on Mobile**: Shift+Ctrl+M in Chrome/Firefox for responsive view
4. **Check Console**: F12 → Console for any errors
5. **Network Tab**: F12 → Network to see API calls and response times
6. **Export Data**: Many dashboards have export buttons for reports
