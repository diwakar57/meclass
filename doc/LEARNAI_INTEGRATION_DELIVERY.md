## 🏗️ Architecture Overview

### High-Level Integration Flow

```
LearnAI Platform
  ↓
LearnAI API (REST)
  ↓
LearnAI Services
  ├─ StudentService (fetch profile)
  ├─ CurriculumService (fetch topic)
  ├─ LearningDNAService (fetch learning profile)
  └─ LearnAIIntegrationService ← NEW
      ├─ Fetch student context
      ├─ Fetch topic context
      ├─ Build OpenMAIC request
      ├─ Call OpenMAIC generation
      ├─ Map output to LearnAI model
      └─ Persist to database
        ↓
OpenMAIC Classroom Engine
  ├─ Generate outlines (LLM)
  ├─ Generate scenes (LLM)
  ├─ Generate actions
  ├─ Generate media (TTS, images, video)
  └─ Return Stage + Scenes

LearnAI Data Layer
  ├─ ai_classroom_sessions
  ├─ session_transcripts
  └─ session_interaction_logs
```

## 📊 Data Model Hierarchy

### Primary Model: AIClassroomSession

```
AIClassroomSession {
  // Identity
  id: UUID
  sessionType: 'ai_classroom_interactive'
  
  // Context
  studentId: UUID
  schoolId: UUID (tenant isolation)
  topicId: UUID
  
  // Customization
  difficultyLevel: 1-10
  teachingStyle: 'friendly' | 'strict' | 'storytelling' | 'socratic'
  duration: seconds
  
  // Content URLs (generated by OpenMAIC)
  contentUrl: string
  videoUrl?: string
  audioUrl?: string
  transcriptUrl?: string
  
  // Embedded Data (from OpenMAIC output mapping)
  sceneData: {
    totalScenes: number
    scenes: AISceneData[]
  }
  
  interactionData: {
    quizData?: SessionQuizData
    discussionLog?: ChatMessage[]
    userResponses?: SessionResponse[]
  }
  
  mediaData: {
    images: MediaReference[]
    generatedAssets: GeneratedAssetReference[]
  }
  
  // Lifecycle
  status: 'generated' | 'started' | 'completed' | 'abandoned'
  generatedAt: Date
  startedAt?: Date
  completedAt?: Date
  
  // Metadata & timestamps
  metadata: Record<string, unknown>
  createdAt: Date
  updatedAt: Date
}
```

### Supporting Models (all in `lib/types/ai-classroom.ts`)

- `AISceneData` — Individual scene from OpenMAIC
- `SlideSceneContent`, `QuizSceneContent`, `InteractiveSceneContent`, `PBLSceneContent` — Scene types
- `SessionQuizData` — Quiz metadata embedded in session
- `SessionTranscript` — Complete session transcript
- `SessionInteractionLog` — Engagement analytics

## 🔐 Security & Tenant Isolation

### Authentication Layer
✅ JWT validation required on all endpoints
✅ `getServerSession()` validates user identity
✅ User role checked for authorization (student/teacher/admin)

### Tenant Isolation
✅ `school_id` fetched from `users` table (implicit in auth)
✅ All queries filter by `school_id`
✅ Cross-school access returns 404 (not 403, prevents enumeration)
✅ Foreign key constraints enforce tenant boundaries

### Authorization Rules
```
GET /api/ai-classroom/sessions/{id}
├─ Student: Can view own sessions only
├─ Teacher: Can view students in their classes
└─ Admin: Can view all sessions in school

POST /api/ai-classroom/sessions/{id}/submit-quiz
├─ Student: Can only submit quiz for own session
└─ Teacher/Admin: Cannot submit on behalf of students

GET /api/ai-classroom/sessions
├─ Default: Lists own sessions
├─ With studentId param: Teachers/admins can filter
└─ Cross-school requests: Rejected (404)
```

### Data Protection
✅ JSONB fields store flexible data (no PII exposure)
✅ Sensitive fields not logged
✅ Timestamps track all mutations
✅ Soft cascading deletes for audit trail

## ⚠️ Error Handling Strategy

### Client Errors (4xx)

| Code | Scenario | Action |
|------|----------|--------|
| 400 | Missing topicId | Re-check request format |
| 400 | Invalid duration | Use 5-120 minutes |
| 401 | No auth token | Login first |
| 403 | Student not in school | Check school_id |
| 404 | Session not found | Session expired or never existed |

### Server Errors (5xx)

| Code | Scenario | Recovery |
|------|----------|----------|
| 500 | OpenMAIC timeout | Retry with simplified request |
| 500 | Media generation failed | Return text-only session |
| 500 | Database error | Transaction rollback, retry |

### Specific Error Responses

```json
{
  "error": "GENERATION_FAILED",
  "message": "Failed to generate from OpenMAIC",
  "details": {
    "reason": "Timeout after 30 seconds",
    "retryable": true
  },
  "requestId": "req_abc123"
}
```

## 📈 Performance Optimization

### Query Optimization
- `idx_acs_school_student` for list queries
- `idx_acs_topic_status` for status filtering
- `idx_acs_created_at` for pagination
- JSONB indexing on `scene_data` if deep queries needed

### Caching Strategy
- Cache student profile (5 min TTL)
- Cache topic metadata (10 min TTL)
- Cache learning DNA (15 min TTL)
- Don't cache sessions (they're pre-generated)

### Generation Performance
- Generation is async (202 Accepted response)
- OpenMAIC can run with streaming progress
- Media generation parallelized
- Session persists even if media fails

## 🔍 Validation Flow

### Request Validation
```
POST /api/ai-classroom/sessions/generate
  ↓
1. Check JWT token valid → 401 if invalid
  ↓
2. Fetch user's school_id → 404 if user not found
  ↓
3. Parse request body → 400 if malformed
  ↓
4. Validate fields:
   - topicId required
   - studentId valid UUID
   - duration 5-120 if provided
   - teachingStyle in enum if provided
  ↓
5. Tenant check: student in school → 404 if not
  ↓
6. Authorization check:
   - If studentId != current user:
     - Must be teacher/admin → 403 if not
     - Target student in school → 404 if not
  ↓
7. Call service → returns session
```

### Session Data Validation (internal)
```
OpenMAIC Result
  ↓
1. Check required fields:
   - id (UUID)
   - stage with scenes
   - duration > 0
  ↓
2. Validate structure:
   - Each scene has id, type, title
   - Scene actions well-formed
   - Quiz data consistent
  ↓
3. Check URLs (if present):
   - Valid URL format
   - No invalid characters
  ↓
4. Warnings logged for:
   - Missing optional fields
   - Unusual scene counts
   - Large data sizes
  ↓
5. Persist if valid, throw error if invalid
```

## 🎯 Key Design Decisions Explained

### 1. Service-Based Architecture
**Decision**: `LearnAIIntegrationService` as static utility class  
**Why**: Consistent with existing service patterns; easy to extend  
**Tradeoff**: No state management, but sessions are stateless anyway

### 2. REST API (not Real-time)
**Decision**: Traditional REST endpoints, no WebSocket  
**Why**: Sufficient for MVP; simpler to maintain  
**Plan**: Add WebSocket for live chat in v2

### 3. JSONB Flexible Storage
**Decision**: Use JSONB for scene_data, interaction_data, media_data  
**Why**: OpenMAIC schema might change; JSONB flexible  
**Tradeoff**: Less queryable; mitigated by extracting key fields to columns if needed

### 4. Loose Coupling via Mapping
**Decision**: `mapOpenMAICOutput()` converts OpenMAIC → LearnAI models  
**Why**: Isolates both systems; allows independent evolution  
**Benefit**: If OpenMAIC changes, only mapping layer updates

### 5. Async Generation (202 Response)
**Decision**: Session generation returns 202 Accepted  
**Why**: OpenMAIC generation takes 10-30 seconds  
**UX**: Client polls or uses Server-Sent Events for progress

## 📞 Support & Troubleshooting

### Common Issues

**Issue**: OpenMAIC generation times out  
**Fix**: Check OpenMAIC service is running; simplify request (fewer media options)

**Issue**: Quiz not grading correctly  
**Fix**: Verify question IDs match; check answer format (array vs string)

**Issue**: Tenant isolation error  
**Fix**: Ensure school_id in auth token; check student belongs to school

**Issue**: Database migration fails  
**Fix**: Check PostgreSQL version >= 12; verify foreign key tables exist
