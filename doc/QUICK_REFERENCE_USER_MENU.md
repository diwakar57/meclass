# Quick Reference: Dashboard User Menu Features

## 🎯 30-Second Quick Start

**All dashboard features are in ONE place:** User menu (top-right corner)

### Find the Menu
- Look for your email + profile icon in **top-right** of screen
- Click to open dropdown menu

### What You Can Do
```
┌─ Your Email
│  Your Role (e.g., Principal)
├─ ✏️  Edit Profile      → Change name, avatar
├─ 🔐 Change Password    → Update password
├─ 🔑 Two-Factor Auth    → Setup 2FA
└─ 🚪 Logout             → Sign out
```

---

## 📋 Feature-by-Feature Guide

### ✏️ Edit Profile
**What:** Update your first name, last name  
**How:** Edit Profile → Fill fields → Save Changes  
**Time:** 30 seconds

### 🔐 Change Password
**What:** Update your password securely  
**How:** Change Password → Enter current password → Enter new password twice → Save  
**Time:** 1 minute  
**Note:** If you have 2FA enabled, you'll need to enter your 2FA code

### 🔑 Two-Factor Authentication (2FA)
**What:** Add extra security to your account  
**How:**
1. Two-Factor Auth → Select method (TOTP/SMS/Email)
2. If SMS: Enter phone number
3. Follow instructions (scan QR code or use secret)
4. Enter verification code
5. Click Verify & Enable

**Methods:**
- **TOTP**: Use apps like Google Authenticator, Authy
- **SMS**: Get codes via text message
- **Email**: Get codes in your email

**Time:** 2 minutes

### 🚪 Logout
**What:** Sign out of your account  
**How:** Click Logout  
**Time:** 1 second

## ❓ Common Questions

### Q: Where is the user menu?
**A:** Top-right corner of your screen. It shows your email and has a profile icon.

### Q: I forgot my password. What do I do?
**A:** Go to login page and click "Forgot Password" (2FA is for after login).

### Q: How is 2FA different from password?
**A:** Password is something you know. 2FA is something you have (phone, authenticator app). Together = more secure.

### Q: Can I change my email?
**A:** Not through the dashboard yet. Contact your admin.

### Q: Will my profile changes show immediately?
**A:** Yes! Changes save instantly.

### Q: Can I disable 2FA?
**A:** Yes! Go to Two-Factor Auth menu and disable. You'll need your password.

### Q: What if I lose my phone with authenticator app?
**A:** You won't be able to access your account until 2FA is disabled. Keep a backup method enabled!

### Q: How secure is this?
**A:** Very! Passwords are hashed, 2FA adds extra layer, all data encrypted in transit.

## 🔐 Security Tips

✅ **DO:**
- Use strong passwords (8+ characters, mix of letters/numbers/symbols)
- Enable 2FA for added security
- Change password periodically (3-6 months)
- Logout when using shared computers
- Keep your 2FA device safe

❌ **DON'T:**
- Share your password with anyone
- Use same password across sites
- Write password on sticky notes
- Login on public WiFi (use VPN)
- Click suspicious links in emails

## 🆘 Troubleshooting

### Modal won't open?
- Try refreshing page (F5)
- Clear browser cache
- Try different browser

### Can't submit changes?
- Check for error message (red box)
- Verify all required fields filled
- Try again (might be temporary)

### Password change fails?
- Verify current password is correct
- Check new passwords match exactly
- If 2FA enabled, include 2FA code

### 2FA code doesn't work?
- Check if code is still valid (codes expire)
- Verify correct method chosen (TOTP vs SMS)
- Try refreshing to get new code

### Locked out of account?
- Contact your administrator
- They can reset your password
- They can disable 2FA temporarily
