# OpenMAIC

OpenMAIC (Open Multi-Agent Interactive Classroom) is an open-source AI classroom platform.

## Quick Start

1. Install dependencies:
   - `pnpm install`
2. Configure at least one LLM API key in `.env.local`.
3. Run development server:
   - `pnpm dev`
4. Open `http://localhost:3000`.

## Build

- `pnpm build`
- `pnpm start`

## Features

- AI-generated classroom outlines and scene content
- Multi-agent classroom interactions
- Slide, quiz, interactive, and PBL scenes
- Whiteboard actions and speech playback
- PPTX and HTML export
